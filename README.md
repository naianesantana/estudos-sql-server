# 🗄️ Jornada de Estudos & Prática em SQL Server

Este repositório é dedicado à documentação contínua da minha evolução prática em bancos de dados relacionais utilizando o **Microsoft SQL Server (T-SQL)**. 

O objetivo principal é consolidar a sintaxe, otimização de consultas e regras de negócio através da resolução de exercícios diários e desafios técnicos aplicados à Análise e Ciência de Dados.

---

## 🛠️ Tecnologias & Ferramentas
* **SGBD:** Microsoft SQL Server
* **Interface:** SQL Server Management Studio (SSMS)
* **Linguagem:** T-SQL (Transact-SQL)
